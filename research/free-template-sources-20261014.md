# Free template sources for Lyre — research, 2026-10-14

## Recommendation

**Start Bootstrap is the closest match for a large supply of free, attractive, MIT-licensed website projects that can become a local preview quickly.** It is an [organization containing separate repositories](https://github.com/StartBootstrap), rather than one universal template monorepo. Its [Bare repository](https://github.com/StartBootstrap/startbootstrap-bare) describes the free library and includes an actual [MIT license](https://github.com/StartBootstrap/startbootstrap-bare/blob/master/LICENSE). Select and verify each free repository; paid products and external form services are separate offerings.

For a broader catalog, add small, reviewed selections from the official [Astro examples](https://github.com/withastro/astro/tree/main/examples), [Next.js examples](https://github.com/vercel/next.js/tree/canary/examples), and [Expo examples](https://github.com/expo/examples). Those are genuine collections of source projects. Their examples vary from self-contained starters to integrations requiring external accounts. A directory listing is a discovery source, not proof that every entry is suitable for automatic import.

The research below covers **29 distinct candidate repositories or source collections**, plus exclusions. It supports a curated catalog rather than automatic ingestion of everything labeled “free.” A runnable website theme is useful, but it does not supply working authentication, payments, inventory, messaging, or an application backend merely because its preview contains those screens.

The minimal Tabler Starter uses CDN resources and needs an offline/pinning decision. |
| Next after an asset cleanup | Astroplate; Bigspring Light; selected AstroWind pages; AdminLTE | Replace demo images where rights are restricted or unclear, inspect analytics/forms and remote resources, then verify the exact resulting project. AstroWind's repository ownership changed; use the resolved source deliberately. |
| Native and full-stack track | Selected Expo examples; Ignite; Electron React Boilerplate; Full Stack FastAPI; Next.js SaaS Starter | Give these an explicit runtime/setup profile. Native toolchains, databases, secrets, service accounts and larger downloads prevent an unconditional “works in minutes” promise. |
| Hold for license/dependency resolution | TailAdmin React; Devias Kit; Minimal UI; Flowbite React Admin; full Tabler demo distribution | MIT template code does not override dependency licenses. Current or potentially resolved ApexCharts versions require separate review. Flowbite also has conflicting package metadata. |

“Little setup” above is an assessment of the documented path, **not a measured time-to-first-preview**. No candidate was installed or executed during this research.

## Exclude or require a different licensing policy

- **[HTML5 UP](https://html5up.net/license):** free commercial/personal use with Creative Commons Attribution 3.0 conditions, **not MIT**. It can be considered for an explicitly attributed non-MIT collection, but it must not be mislabeled or imported into an MIT-only feed. Attribution-free Pixelarity offerings are separate.
- **[BootstrapMade](https://bootstrapmade.com/license/):** current page describes its own free/pro/premium terms, footer requirements, restrictions on client work for free versions, and prohibitions on mass redistribution and SaaS builders. Its general opening copy and detailed free-license copy differ in breadth; neither establishes MIT. Exclude from the redistributable catalog unless separate permission specifically covers this use. The free form markup also excludes its working PHP/AJAX script.
- **[Cruip Open React/Next template](https://github.com/cruip/open-react-template#terms-and-license):** README identifies GPL and additionally discourages republication/redistribution/resale. That inconsistent combination needs clarification, and it is not MIT. Exclude from the requested MIT batch; do not copy its templates into Lyre on the strength of “free.”
- **[Gitfolio](https://github.com/imfunniee/gitfolio), [license](https://github.com/imfunniee/gitfolio/blob/master/LICENSE):** GPL-3.0; archived, last pushed 2022-02-19. Exclude from this MIT collection.
- **[Awesome Landing Page](https://github.com/nordicgiant2/awesome-landing-page#license):** a discovery list with CC-BY-4.0 licensing for that list, last pushed 2022-01-02. It contains links to independent projects. Its license does not relicense those projects. The same rule applies to MIT-licensed “awesome” lists and template aggregators: verify the linked source, its files and assets separately.

## Conditions that materially affect the catalog

**Redistribution:** preserve each applicable copyright/license text and relevant third-party notices in source copies and acquired artifacts. A root MIT grant covers what its owner can license; it does not relicense npm packages, fonts, stock photos, logos, embedded services or linked templates. Avoid advertising every dependency/asset as MIT simply because a template's own code is MIT.

**ApexCharts:** the [current upstream licensing page](https://apexcharts.com/license/) describes community eligibility restrictions and separate commercial/OEM redistribution licensing. This is a concrete issue for developer-platform distribution, not merely a distinction between free and paid Pro templates. TailAdmin's inspected manifest includes ^7.1.0. Other templates specify older majors, whose exact artifacts/licenses must be checked independently. Replacing affected charts with an appropriately licensed alternative is a possible adaptation, but that work and resulting verification were not performed here.

**Assets:** Astroplate and Bigspring Light explicitly withhold clearance for their demonstration images. Tailwind Toolbox's hero illustration has separate attribution. AdminLTE lists multiple image sources; Ignite and Tauri reserve branding. Retain proven notices, replace restricted/unclear assets with owned or explicitly redistributable ones, and record those substitutions. An upstream screenshot is also a separate asset to review before using it as a Lyre marketplace preview.

**Truthful project labels:** describe a static UI as a website or UI starter. Describe a full-stack starter's working owners and prerequisites. For example, “Shopify storefront; requires Shopify configuration” is accurate for Next.js Commerce. A sign-in form does not establish working authentication, and a Stripe integration does not establish an activated merchant account or live billing.

**Practical acquisition:** record canonical source, selected subdirectory, pinned commit/tag, archive digest, license/notice paths, replaced assets, supported runtime and actual start/build commands. For source collections, acquire the chosen standalone example and applicable parent notices. Inspect lifecycle/install scripts and required network services before offering automated setup. Run install/build/preview acceptance against the exact imported project before claiming that it opens in minutes.

## Verification limits and handoff

This was read-only primary-source research: public GitHub repository metadata, actual license files, READMEs and selected manifests/source files, plus the maintainers' license/setup pages. API metadata was cross-checked against license content, which exposed the Flowbite mismatch and scope notes that a GitHub license badge omits. The report is the only marketplace file authored by this workstream.

No third-party template, installer, generator, package lifecycle script or application was executed. No dependency install, build, browser interaction, accessibility test, vulnerability scan, exhaustive transitive-license audit, native acceptance or service signup was performed. Source snapshots were read from mutable branches; this report does not claim an immutable accepted artifact or a measured startup duration. No credentials were requested or used, no commits were created, and nothing was pushed or published by this research workstream.

The implementation owner is adding the first Start Bootstrap group separately. Inclusion in this report is a source recommendation or documented hold, not evidence that a candidate has already been added to Lyre or verified there.
