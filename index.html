Twelve MIT-licensed projects: ten website templates from Start Bootstrap plus a working to-do list and drawing pad from 50 Projects in 50 Days. Download or clone, then run npm start with Node 22 or newer. No package dependencies, account or database needed. Online fonts and UI libraries need internet access.

The website layouts use sample content and include no email, authentication or checkout backend. The to-do list and drawing pad are working local browser apps.
