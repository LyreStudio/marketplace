# Lyre Marketplace

Browse the [Marketplace](https://lyrestudio.github.io/marketplace/) to preview, download or clone an editable project.

## Twelve new MIT projects

Ten prepared websites adapt individually verified free [Start Bootstrap](https://github.com/StartBootstrap) repositories. Two functioning browser apps adapt [50 Projects in 50 Days](https://github.com/bradtraversy/50projects50days): a to-do list with browser-local storage and a drawing pad with touch controls and PNG export. Install Node 22 or newer, clone or extract one project, then run `npm start`. No npm dependencies, account, database or API key is required. Online fonts and UI libraries need internet access.

In a Lyre version containing the reviewed recipe, Marketplace → template → **Choose folder & install** prepares the local runtime and opens the project. Existing releases can use **Add project → Clone repository** or download and add the folder; compiled recipes require an app update. Explicit Supabase catalog configurations retain their separately administered feed.

The website templates contain sample content. Contact/signup forms do not send information, storefront controls do not implement checkout, and dashboard account screens do not authenticate. Keep the existing [Stockroom](https://lyrestudio.github.io/stockroom/), [Project Desk](https://lyrestudio.github.io/project-desk/) and [Daybook](https://lyrestudio.github.io/daybook/) browser apps for local inventory, task and note workflows.

## Source and license evidence

[Research: 29 candidate sources](research/free-template-sources-20261014.md) · [Pinned template/download manifest](templates.json) · [Business references](business-catalogs.md) · [Community extensions](https://github.com/LyreStudio/extensions)

Each prepared template keeps its original MIT license, upstream commit and archive or individual-file SHA-256, source notices, setup guide, design/agent guides, validation record and real screenshots. All bundled upstream images and logos were replaced with original MIT SVG sample artwork. Remote fonts, icons and UI libraries retain their own licenses and availability; template MIT terms do not relicense third-party resources. See each project's THIRD-PARTY.md and TEMPLATE.json.

## Feed compatibility

`catalog-v2.json` revision 2026101402 contains the three existing browser apps plus twelve prepared projects. `catalog-v1.json` retains only Stockroom, Project Desk and Daybook for older strict clients. `catalog-source.json` is the reviewed input; templates.json is public download/provenance metadata, never executable Lyre configuration. Catalog data cannot supply installation commands, source pins or permissions.

The older native source forks remain reachable: [Ordinary Puzzles](https://github.com/LyreStudio/ordinary-puzzles) (MIT), [Breathly](https://github.com/LyreStudio/breathly) (MPL-2.0) and [Habit Tracker](https://github.com/LyreStudio/habit-tracker) (MIT). Their native SDK, setup and validation limits remain in their guides. They are not added to the current app-project feed by this change.

Validation and publication receipts: [VALIDATION.md](VALIDATION.md). A catalog listing and a local browser pass do not certify production security, native compatibility or an installed Lyre release.
